# STA cheatsheet

1. Wi‑Fi → `TELLO-…`
2. `python set_sta_mode.py` and enter the SSID and password (this lab: hackathon / hackathon)
3. Wait ~1 min
4. Wi‑Fi → `hackathon`
5. `python find_tello.py` → save `TELLO_IP`
6. Optional: `python live_video.py` (q to quit)

Needs **2.4 GHz**. USB cable = charging only, not Wi‑Fi setup.
